# Animales — fotos y voces

## Fotos (modo realista)

PNG portraits for the Animales game **realista** graphics style (`/animals/images/<id>.png`).
Sized to 256×256. Includes casa, mar, campo, dinosaurios y jungla.
Replace with your own photos anytime; keep the same filenames.

## Voces

Pre-recorded spoken names (`/animals/sounds/<id>.mp3`). One clip per animal id.
The matcher plays the local file when a piece is picked; TTS is only a fallback.
