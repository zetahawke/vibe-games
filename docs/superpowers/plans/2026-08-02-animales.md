# Juego de Animales Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a toddler-friendly Spanish drag-to-shadow animals game (3–4 SVG animals per round, three drop modes) unlocked from the hub, reusing suite auth.

**Architecture:** Pure domain logic (catalog, round pick, drop rules, settings) + DOM `AnimalsSession` with Pointer Events. Hub opens a settings modal then starts the game via router. No Three.js.

**Tech Stack:** Vite 6, TypeScript, Vitest, HTML/CSS/SVG, existing `@/` aliases and `STORAGE_PREFIX`.

## Global Constraints

- UI language: Spanish only
- Devices: PC (mouse) and tablet (touch) via Pointer Events
- Persistence: `localStorage` only; drop mode per username; no mid-round save
- Rounds: length uniformly 3 or 4; unique ids from fixed catalog of 8
- Drop modes: `libre` | `suave` | `guiado`; default `guiado`
- Settings UI: hub modal only (before Jugar), not in-game gear
- Spec: `docs/superpowers/specs/2026-08-02-animales-design.md`

```ts
import { ANIMAL_IDS, type AnimalId } from './catalog';

export { ANIMAL_IDS, type AnimalId };

export function pickRound(rng: () => number = Math.random): AnimalId[] {
  const count = rng() < 0.5 ? 3 : 4;
  const pool = [...ANIMAL_IDS];
  const out: AnimalId[] = [];
  for (let i = 0; i < count; i++) {
    const idx = Math.floor(rng() * pool.length);
    out.push(pool.splice(idx, 1)[0]!);
  }
  return out;
}
```

**Interfaces:**
- Consumes: `AnimalId` from catalog
- Produces:
  - `export type DropMode = 'libre' | 'suave' | 'guiado'`
  - `export type DropFeedback = 'none' | 'success' | 'softFail'`
  - `export function resolveDrop(mode: DropMode, animalId: AnimalId, targetId: AnimalId | null): { accept: boolean; feedback: DropFeedback }`
  - `export function getDropMode(username: string): DropMode` — default `'guiado'`
  - `export function setDropMode(username: string, mode: DropMode): void`
  - Storage key: `` `${STORAGE_PREFIX}animals:settings:${username}` `` → `JSON { dropMode }`

**Rules:**
- `targetId === null` (miss): `{ accept: false, feedback: mode === 'suave' ? 'softFail' : 'none' }`
- `targetId === animalId`: `{ accept: true, feedback: 'success' }`
- mismatch + `guiado`: `{ accept: false, feedback: 'none' }` (return home, no soft fail required)
- mismatch + `libre`: `{ accept: false, feedback: 'none' }`
- mismatch + `suave`: `{ accept: false, feedback: 'softFail' }`

- [ ] **Step 1: Write failing tests**

```ts
describe('resolveDrop', () => {

    for (const mode of ['libre', 'suave', 'guiado'] as const) {
      expect(resolveDrop(mode, 'perro', 'perro')).toEqual({
        accept: true,
        feedback: 'success',

    expect(resolveDrop('guiado', 'perro', 'gato')).toEqual({ accept: false, feedback: 'none' });

    expect(resolveDrop('suave', 'perro', 'gato')).toEqual({ accept: false, feedback: 'softFail' });
```

`settings.ts`:

```ts
import { STORAGE_PREFIX } from '@/config/gameConfig';
import type { DropMode } from './dropRules';

export type { DropMode };

function key(username: string): string {
  return `${STORAGE_PREFIX}animals:settings:${username}`;
}

export function getDropMode(username: string): DropMode {
  const raw = localStorage.getItem(key(username));
  if (!raw) return 'guiado';
  try {
    const data = JSON.parse(raw) as { dropMode?: string };
    if (data.dropMode === 'libre' || data.dropMode === 'suave' || data.dropMode === 'guiado') {
      return data.dropMode;
    }
  } catch {
    /* ignore */
  }
  return 'guiado';
}

export function setDropMode(username: string, mode: DropMode): void {
  localStorage.setItem(key(username), JSON.stringify({ dropMode: mode }));
}
```

Export `DropMode` from `dropRules.ts` (settings imports type from there to avoid cycles — or define `DropMode` once in `dropRules` and re-export from settings).

### Task 4: AnimalsSession (DOM play)

**Files:**
- Create: `src/game/animals/AnimalsSession.ts`
- Modify: `src/styles/main.css` (animals classes)

**Interfaces:**
- Consumes: `pickRound`, `resolveDrop`, `animalSvg`, `animalName`, `DropMode`
- Produces: `export class AnimalsSession { constructor(root: HTMLElement, username: string, dropMode: DropMode, onExit: () => void); dispose(): void }`

**Behavior:**
1. Clear `root`, mount `.animals-screen` with `.shadows-row`, `.animals-row`, header with **Salir**.
2. Start round: pickRound → create shadow slots + draggable animal buttons (innerHTML from `animalSvg`).
3. Drag with pointerdown/move/up + `setPointerCapture`; on up, hit-test elementFromPoint under center of dragged piece against `[data-shadow-id]:not([data-filled])`.
4. `resolveDrop` → accept: snap into shadow, mark filled, disable drag; softFail: add `.shake` class + optional `playSoftFail()` oscillator beep; always return home if !accept.
5. When all filled: show `.animals-celebrate` overlay “¡Muy bien!” + **Otra vez** (new round) + **Salir** (`onExit`).
6. `dispose()` removes listeners / clears root content owned by session.
